
TÉCNICAS DE ELICITACIÓN
1. Revisión documental
Se analizaron fuentes académicas, informes del ICFES, MEN, PISA y estudios de la Universidad de Antioquia para identificar la problemática.
2. Análisis del estado del arte
Se evaluaron plataformas, aplicaciones y recursos educativos existentes para identificar fortalezas, debilidades y oportunidades de mejora.
3. Benchmarking
Se compararon herramientas como videos educativos, páginas web y aplicaciones matemáticas para definir funcionalidades clave del sistema propuesto.
4. Análisis de contexto
Se estudiaron las condiciones socioeconómicas y educativas de estudiantes de Medellín (estratos 1–3).
